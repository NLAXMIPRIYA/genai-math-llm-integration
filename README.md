## Integration of a Mathematical Calculation with a Chat Completion System using LLM Function-Calling

### AIM:
To design and implement a Python function for calculating the volume of a cylinder and integrate it with a chat completion system using the function-calling feature of a Large Language Model (LLM).

### PROBLEM STATEMENT:
To develop a Python-based application that calculates the volume of a cylinder using its radius and height. The application integrates a mathematical function with an LLM-based chat completion system, allowing the LLM to identify the user's request, extract the required parameters, invoke the appropriate Python function, and return the calculated result in a conversational format.

### DESIGN STEPS:

#### STEP 1:
Define a Python function named `calculate_cylinder_volume()` that accepts the radius and height of a cylinder as input parameters and calculates its volume using the mathematical formula.

#### STEP 2:
Configure the OpenAI API client and define the mathematical function as a tool with its name, description, and required parameters. Send the user's prompt along with the tool definition to the LLM using the chat completion system.

#### STEP 3:
Allow the LLM to identify when the mathematical function needs to be called. Extract the arguments generated by the LLM, execute the corresponding Python function, and pass the calculated result back to the LLM to generate a user-friendly response.

### PROGRAM:

```python
import openai
import json
import math

# Define the mathematical function
def calculate_cylinder_volume(radius, height):
    volume = math.pi * radius * radius * height
    return volume

# Define the function schema
functions = [
    {
        "name": "calculate_cylinder_volume",
        "description": "Calculate the volume of a cylinder",
        "parameters": {
            "type": "object",
            "properties": {
                "radius": {
                    "type": "number",
                    "description": "Radius of the cylinder"
                },
                "height": {
                    "type": "number",
                    "description": "Height of the cylinder"
                }
            },
            "required": ["radius", "height"]
        }
    }
]

# Send prompt to the LLM
messages = [
    {
        "role": "user",
        "content": "Calculate the volume of a cylinder with radius 5 and height 10."
    }
]

response = openai.ChatCompletion.create(
    model="gpt-6-luna",
    messages=messages,
    functions=functions,
    function_call="auto"
)

# Extract function call
message = response.choices[0].message

if message.get("function_call"):
    function_name = message["function_call"]["name"]
    arguments = json.loads(message["function_call"]["arguments"])

    # Execute the Python function
    if function_name == "calculate_cylinder_volume":
        result = calculate_cylinder_volume(
            arguments["radius"],
            arguments["height"]
        )

    # Add function result to conversation
    messages.append(message)
    messages.append({
        "role": "function",
        "name": function_name,
        "content": str(result)
    })

    # Generate final response
    final_response = openai.ChatCompletion.create(
        model="gpt-6-luna",
        messages=messages
    )

    print(final_response.choices[0].message["content"])
```

### OUTPUT:

The user provides the following prompt:

**"Calculate the volume of a cylinder with radius 5 and height 10."**

The LLM identifies the mathematical function, extracts the radius and height, and invokes the Python function.

The calculated volume is:

**Volume = 785.3982 cubic units**

The LLM returns the calculated result as a conversational response.
